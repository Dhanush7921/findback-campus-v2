# Staff process

1. **Register** each handed-in item and add photos (Take photo or From gallery; previews are shown before you submit). The public description stays generic. Private verification details (contents, serial numbers) are never shown to students.
2. **Match**: propose a match when it is plausible. The reporter sees only the public description.
3. **Claim**: the reporter submits ownership evidence. Approve only when the evidence matches, the features match, and there is no conflicting claim. Otherwise reject or mark it Disputed.
4. **Handover** (Handovers page), when the receiver is at the counter:
   - Check their college ID or government ID. Record the ID type and the last 4 digits.
   - Start the handover and read the 6-digit code to the receiver. The receiver enters it on **their own** signed-in phone, types their name and confirms receipt.
   - Hand over the item, then press **Confirm release**. Only now does the complaint become *Returned*.
   - For a **proxy**, the owner first authorises the proxy's phone in their portal, and the proxy signs in as a guest with that phone.
   - **Proof of handover** (button on each handover): add handover photos or documents, for example a signed register page. If Settings requires proof, release is blocked until at least one file is added.
5. **Home delivery** (Settings → enable home delivery):
   - Choose *Home delivery*, the delivery staff member and the address. The address is admin-only.
   - At the doorstep, the delivery staff opens *Proof of handover*, checks the photo ID, presses **Issue doorstep code**, and the recipient confirms on their own phone.
   - The delivery staff uploads a **delivery proof** photo and presses **Record delivery completed now**, which records the actual time.
   - A staff member reviews the acknowledgment and proof, then presses **Finalise delivery**. With two-staff mode on, this must be someone other than the courier. Only then does the complaint become *Returned*.
6. Every step is in the audit log, which management can see read-only.

**Lost phone**: Registry → update the student's phone. This revokes their old sessions.
